SwitchAction

Run a short, non-retried POST once, then hand the same loading workflow to a retryable, read-only GET stream.

+page.py 
from hyperdjango.actions import Signal, action


class PageView(HyperView):
    @action(method="POST", retry=False)
    def start_build(self, request, package_id: str):
        # Commit a bounded transaction or durably enqueue work.
        job = start_package_build(package_id=package_id)

        # The Python reference supplies the action name, GET method,
        # retry policy, and current endpoint automatically.
        return self.watch_build.switch_to(job_id=str(job.pk))

    @action(method="GET", retry=True)
    def watch_build(self, request, job_id: str):
        # Read-only and safe to execute again after reconnecting.
        for snapshot in watch_job(job_id):
            yield Signal(name="build", value=snapshot)

Safety boundary

switch_to() does not make the POST idempotent. Disable retry on the command, persist a discoverable outcome before switching, and keep the destination strictly read-only and replay-safe.
